# Theme screenshots (Phase 22)

Home, Garden, Review, Cloze, Chat, Journal and Textbook in the Garden light theme and the Solarized
dark theme, at phone (390 px) and desktop (1280 px) width. File names are
`<theme>-<size>-<screen>.png`. Refresh them with:

```sh
cd apps/web && THEME_SCREENS=1 pnpm exec playwright test theme-screens --project=desktop
```
